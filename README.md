# Atlas Dev Days 2026

## About the Project

Atlas Dev Days 2026 is a responsive event website for a fictional technology event focused on web development, modern technologies, and entrepreneurship.

The website provides visitors with information about the event, its programme, its speakers, and the registration process.

## Pages

* **Home (`index.html`)** — Introduces the event and presents key statistics and featured speakers.
* **Programme (`programme.html`)** — Displays the event schedule, dates, sessions, and activities.
* **Speakers (`intervenants.html`)** — Introduces the speakers and their professional roles and topics.
* **Registration (`inscription.html`)** — Provides a registration form for participants.

## Technologies Used

* HTML5
* CSS3
* Flexbox
* Responsive design using CSS media queries

## Features

* Responsive layout for desktop and mobile screens.
* Shared navigation menu across all pages.
* Consistent visual identity and typography.
* Event programme organized by date and session.
* Speaker profiles with links to LinkedIn.
* Registration form with HTML validation.
* Reusable CSS classes for consistent styling.

## Getting Started

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

You can also use the **Live Server** extension in Visual Studio Code to preview the website and see your changes as you edit the files.

## Responsive Design

The website is designed for desktop and mobile screens, with a CSS media query at `768px` to adapt the layout to smaller devices.
